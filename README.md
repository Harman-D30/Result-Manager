# Student Result Manager

A simple Python-based Student Result Manager System that allows users to add, view, and check student results through a menu-driven interface.

## Features
- Add student names and marks
- View all student results
- Check pass/fail status (27 marks required to pass)
- Exit the program

## Technologies Used
- Python
- Dictionaries
- Loops and conditional statements
- User input and output

## How to Run
1. Save the code as `result_manager.py`.
2. Run the following command:

   ```bash
   python manager.py
   ```

**Note:** Student results are stored temporarily and are lost when the program exits.
